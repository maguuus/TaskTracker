# TaskTracker — Описание продукта

## Что такое TaskTracker

TaskTracker — веб-приложение для управления задачами в команде. Работа организована вокруг **досок** с **колонками** (например: «К выполнению», «В работе», «Готово»), в которых находятся **карточки задач**.

---

## Вход в систему

Для работы с приложением необходимо зарегистрироваться или войти в существующий аккаунт.

- **Регистрация** — укажите email и придумайте пароль
- **Вход** — введите email и пароль
- После входа выдаётся токен доступа, который позволяет работать с досками и задачами

---

## Доски

После входа вы попадаете на главную страницу со **списком ваших досок**.

### Создание доски

Нажмите «Создать доску» и введите название.

### Переименование доски

Откройте доску и измените её название через настройки.

### Удаление доски

Удалите доску через настройки. Вместе с доской удаляются все её колонки и задачи.

---

## Колонки

Каждая доска состоит из **колонок** — этапов работы над задачами. Колонкам можно задавать произвольные названия, например: «Бэклог», «В работе», «На ревью», «Готово».

Колонки отображаются в виде таблицы на странице доски.

---

## Задачи

Задачи создаются внутри колонок.

### Создание задачи

Нажмите «Добавить задачу» внутри нужной колонки и заполните поля.

### Редактирование задачи

Откройте карточку задачи и измените любое поле.

### Перемещение задачи

Задачу можно перенести в другую колонку — для этого выберите нужную колонку в карточке задачи.

### Удаление задачи

Удалите задачу через карточку задачи.

---

## Поля задачи

| Поле | Описание |
|---|---|
| **Название** | Краткое описание задачи |
| **Приоритет** | Уровень важности: Низкий / Средний / Высокий |
| **Срочность** | Насколько быстро необходимо выполнить задачу |
| **Выполняющий** | Участник, ответственный за задачу |
| **Даты** | Дата начала и дедлайн |
| **Описание** | Подробное описание, контекст, ссылки |
