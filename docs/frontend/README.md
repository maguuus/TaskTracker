# Фронтенд — Техническая документация

## Стек

| Компонент | Версия |
|---|---|
| Фреймворк | React 19 |
| Сборщик | Vite 8 |
| Роутинг | React Router v7 |
| UI-библиотека | Bootstrap 5 |
| Язык | JavaScript (JSX) |

---

## Структура проекта

```
Frontend/
├── index.html            # HTML-оболочка приложения
├── vite.config.js        # Конфигурация Vite
├── package.json          # Зависимости и скрипты
├── eslint.config.js      # Конфигурация линтера
└── src/
    ├── main.jsx          # Точка входа — монтирование React-приложения
    ├── App.jsx           # Корневой компонент, роутер, навигация
    ├── App.css           # Глобальные стили приложения
    ├── index.css         # Базовые CSS-сбросы
    └── pages/
        ├── Home.jsx      # Главная страница — список досок
        ├── Login.jsx     # Страница входа / регистрации
        └── Board.jsx     # Страница доски — колонки и задачи
```

---

## Маршруты

| Путь | Компонент | Назначение |
|---|---|---|
| `/` | `Home` | Список досок пользователя |
| `/login` | `Login` | Вход и регистрация |
| `/board` | `Board` | Просмотр и редактирование доски |

---

## Запуск

```bash
cd Frontend
npm install
npm run dev
# http://localhost:5173
```

### Прочие скрипты

| Команда | Действие |
|---|---|
| `npm run build` | Сборка для production (`dist/`) |
| `npm run preview` | Предпросмотр production-сборки |
| `npm run lint` | Проверка кода линтером (ESLint) |

---

## Зависимости

### Production

| Пакет | Назначение |
|---|---|
| `react` / `react-dom` | UI-фреймворк |
| `react-router-dom` | Клиентский роутинг |
| `bootstrap` | CSS-компоненты и утилиты |

### Development

| Пакет | Назначение |
|---|---|
| `vite` | Сервер разработки и сборщик |
| `@vitejs/plugin-react` | JSX-трансформация через Babel |
| `eslint` + плагины | Статический анализ кода |
